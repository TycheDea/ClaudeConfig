# Phase B3 — Props + Zone Dressing (subplan)

Source: `zesty-bubbling-acorn.md`, Plan B / Phase B3, planned 2026-07-23.
Puts the pivot's prop set into the running game through the proven A3 chain
(`prop_hi3dgen → prop_cleanup → prop_texture → preprocess_prop → gen_prop`,
resumable, multiview/MaterialAnything texture stage): five new prop classes
generated against the locked Castilian direction (`docs/visual-quality.md`
§A — VQ-A4's numbers are locked targets), the start zone re-dressed through
them, the east zone ("Emberwood Rest") resurrected from its parked state
with the worn_cobble ground set B2 held for it, and the portal re-themed
candle-gold. **Scope boundary — B3 does NOT touch:** characters (B4), VFX
RONs / telegraph constants / class emissives (B5), any renderer code, the
HDRI / ground-set fixtures / fog+palette values B2 landed (the user approved
the environment as-is — east's *new* fog values are B3 authoring, not a
retune of B2's), and nothing in the **feel-check fix batch's** lanes
(`preprocess.mjs` rigid-bind offsets, `weapons.rs` socket matrix, the camera
orbit controller) — that batch runs independently of B3; do not plan around
it, do not touch its files.

This file breaks the phase into 9 single-agent tasks plus the gate. The
orchestrator dispatches one agent per task, verifies with the given command
(never prose), commits on green, and strikes the checkbox. Order is the
listed order and it is load-bearing: B3.1 (concepts) before all geometry
(VRAM sequencing — fact 5); B3.2/B3.3 (candidate batches) before B3.4
(selection); B3.4 before B3.5 (only winners are installed); B3.5 before
B3.6/B3.7 (lint requires referenced files on disk); B3.6 before B3.8
(erasure only after the last dead_quiver_trunk ref is gone); B3.9 (portal)
is order-independent and may run any time after approval.

Tiers (campaign routing table): **fable** = art-direction judgment + real
integration risk (candidate selection; both zone-dressing tasks — placement
composition and east's fog authoring anchored to measured data); **sonnet**
= generation runs (prompt/reseed judgment included — A1.6/A2.10/B2
precedent), install/erasure mechanics, and the portal recolor (band-mapped
from the locked VQ-A4 table); nothing here is haiku-worthy. Per-prop
**vision selection is recorded in this file's Decision log** (A2.8/A3.12
precedent), judged with crispness as an explicit axis (2026-07-23 lesson).

**Shell discipline (all tasks): FOREGROUND commands only** — background
shells die silently on this box (3× precedent). One candidate per foreground
invocation, ~10 min explicit timeout; never `run_in_background`.
