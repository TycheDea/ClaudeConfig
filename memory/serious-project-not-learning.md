origins: "this project is beyond that already, now its a serious project." The
old `Agentic-Coding-Learning-Path.md` was removed from the repo root.

**Why:** Earlier the project followed a learn-by-building methodology, and advice
was sometimes framed around educational payoff (e.g. "write your own ECS to learn").
That framing is now wrong.

**How to apply:** Evaluate all technical decisions (dependencies, rewrites,
architecture) purely on engineering merit — maintenance cost, performance,
shipping the game. Don't suggest building things from scratch for the sake of
learning, and don't reference the learning-path methodology. See also
[[dev-singleplayer-pack]] for the current scope.
