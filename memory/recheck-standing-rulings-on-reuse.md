Fires when a subplan reuses an existing pipeline or tool chain.

**Why:** a subplan adopted "the proven prop chain" wholesale and nobody checked it against the standing image-base ruling ([[image-base-zimage]]); the user caught it at session end. "Proven" describes the past; rulings describe the present. A tool choice inherited silently is a decision made without checking it.

**How to apply:** list the standing rulings (memory index + ruling notes) that touch each tool in the reused chain; confirm compliance or record the divergence as a decided-while-unsure item.
