Fires when citing a run's numbers in a ruling, report, or doc.

**Why:** cited full-stage runs were only re-checkable because a tool's output folder happened to retain copies; two decision-bearing metric scripts were ad-hoc and unreproducible until recommitted.

**How to apply:** keep the outputs (or point the doc at retained copies), and commit any script that produced a decision-bearing number. Related: [[background-work-pitfalls]].
